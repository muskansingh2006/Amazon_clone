# Amazon_clone
🛒 Amazon Clone | A frontend e-commerce website inspired by Amazon, built using HTML5 and CSS3. Features an Amazon-inspired user interface with product sections, navigation bar, search bar, and shopping layouts.
🚀 Features

* Amazon-inspired homepage design.
* Navigation bar and search section.
* Product categories and shopping sections.
* Product display layouts.
* CSS styling for a clean and organized interface.

🛠️ Technologies Used

* HTML5 – For structuring the webpage.
* CSS3 – For styling and layout design.
